🎯 CARACTERÍSTICAS CLAVE
═════════════════════════════════════════════════════════════════════════════

1. VERTICAL SLICING
   ✓ Cada slice (waitlist, hall-of-fame, social-pulse) es autónomo
   ✓ Puedes eliminar un slice sin romper la app
   ✓ Equipos pueden trabajar en paralelo

2. ARQUITECTURA HEXAGONAL
   ✓ Domain (puro) → no conoce Angular, HTTP, ni UI
   ✓ Application → Use Cases orquestadores
   ✓ Infrastructure → Adaptadores concretos (HTTP, UI)
   ✓ Fácil cambiar de HTTP a WebSocket sin tocar dominio

3. SCREAMING ARCHITECTURE
   ✓ Nombres que explican qué hace el sistema
   ✓ join-waitlist.use-case.ts = Unirse a lista de espera
   ✓ Sin necesidad de leer código para entender
   ✓ Claridad inmediata para nuevos devs

4. ANGULAR 21 SIGNALS
   ✓ Reactividad moderna sin RxJS innecesario
   ✓ Performance optimizado
   ✓ Sintaxis limpia: signal() en lugar de .subscribe()
   ✓ Computed signals para derivaciones

5. COMPONENTES STANDALONE
   ✓ 100% standalone (sin NgModules)
   ✓ Inyección granular
   ✓ Composición directa
   ✓ Menos boilerplate

6. SMART & DUMB COMPONENTS
   ✓ Smart: Containers que inyectan servicios
   ✓ Dumb: Presentacionales reutilizables
   ✓ @input/@output para comunicación clara
   ✓ Fácil testear componentes dumb

7. BILINGÜISMO
   ✓ EN/ES sin librería i18n
   ✓ Cambio dinámico con Signals
   ✓ Persiste en localStorage
   ✓ Fácil agregar idiomas

8. DESIGN SYSTEM

🎯 FLUJO DE DATOS (EJEMPLO)
═════════════════════════════════════════════════════════════════════════════

Usuario hace clic en botón
    ↓
waitlist-form.component (Dumb) emite @output()
    ↓
waitlist.container.ts (Smart) recibe evento
    ↓
container inyecta JoinWaitlistUseCase y ejecuta
    ↓
Use Case inyecta WaitlistRepository (puerto abstrato)
    ↓
En Desarrollo: HttpWaitlistAdapter (implementación real)
En Testing: MockWaitlistAdapter (mock)
    ↓
Adapter hace HTTP GET/POST
    ↓
Respuesta actualiza signal en Use Case
    ↓
Template reactivo se actualiza automáticamente
    ↓
Usuario ve resultado (sin .subscribe() necesario)
